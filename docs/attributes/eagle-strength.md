# Eagle Strength

Eagle Strength lets you move more freely in heavy equipment, carry more and chop and mine faster.

<div class="nd-infobox" markdown>

| | |
| --- | --- |
| **Demigods** | [Eir](../demigods/eir.md), [Freyja](../demigods/freyja.md), [Hraesvelgr](../demigods/hraesvelgr.md) |
| **Condition** | Always active |
| **Config ID** | `EagleStrength` |
| **Config section** | `[Attribute Eagle Strength]` |

</div>

<!-- IMAGE: Eagle Strength attribute icon -->

## Effects

| Effect | Value |
| --- | --- |
| Movement penalty from equipment ignored | Up to 20% |
| Extra damage to trees with an axe | +25% |
| Extra damage to ores with a pickaxe | +50% |

## Scaling

Extra carry weight: 1 [per level](../getting-started/glossary.md#per-level).

| | Lv 0 | Lv 50 | Lv 100 |
| --- | ---: | ---: | ---: |
| Extra carry weight | 0 | 50 | 100 |

## Notes

- The movement penalty counts all equipment together.
- Example: 30% total penalty from [heavy armor](../getting-started/glossary.md#heavy-armor), weapon and shield
  slows you by only 10%.
- Unlike [Bear Strength](bear-strength.md), it adds no extra melee damage.
