# Eagle Agility

Eagle Agility is Hraesvelgr's own attribute: he attacks faster with swords and polearms and moves faster.

<div class="nd-infobox" markdown>

| | |
| --- | --- |
| **Demigod** | [Hraesvelgr](../demigods/hraesvelgr.md) |
| **Condition** | Always active; no speed bonus while encumbered |
| **Config ID** | `EagleAgility` |
| **Config section** | `[Attribute Eagle Agility]` |

</div>

## Attack speed

| Weapon | Attack speed |
| --- | ---: |
| One-handed swords | +15% |
| Two-handed swords | +35% |
| Polearms | +35% |

## Movement

| Effect | Value |
| --- | --- |
| Movement speed | +10% |

## Notes

- **Movement speed:** applies to walking, jogging, sprinting, sneaking and swimming, but not while encumbered, and
  does not change jump height. Adds up with other movement speed bonuses. Setting:
  `[(Special Modifiers)] Special Movement Speed Modifier (%)`.
- With [Hare Legs](hare-legs.md) as well (Hraesvelgr has both by default), movement speed is +20%.
