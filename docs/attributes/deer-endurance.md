# Deer Endurance

Deer Endurance makes your stamina come back faster and start regenerating sooner after you use it.

| | |
| --- | --- |
| **Demigods** | [Eir](../demigods/eir.md), [Fenrir](../demigods/fenrir.md), [Freyja](../demigods/freyja.md), [Kvasir](../demigods/kvasir.md), [Ullr](../demigods/ullr.md) |
| **Condition** | Always active |
| **Config ID** | `DeerEndurance` |
| **Config section** | `[Attribute Deer Endurance]` |

</div>

<!-- IMAGE: Deer Endurance attribute icon -->

## Effects

| Effect | Value |
| --- | --- |
| Delay before stamina starts to regenerate | 0.5 s (vanilla: 1 s) |

## Scaling

Stamina regeneration rate grows evenly from 150% at level 0 to 200% at level 100
([per level](../reference/glossary.md#per-level)).

| | Lv 0 | Lv 50 | Lv 100 |
| --- | ---: | ---: | ---: |
| Stamina regeneration rate | 150% | 175% | 200% |
