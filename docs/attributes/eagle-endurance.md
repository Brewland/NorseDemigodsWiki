# Eagle Endurance

Eagle Endurance is Hraesvelgr's own attribute: he has more stamina, regenerates it faster and sooner, and uses less of
it when attacking.

<div class="nd-infobox" markdown>

| | |
| --- | --- |
| **Demigod** | [Hraesvelgr](../demigods/hraesvelgr.md) |
| **Condition** | Always active |
| **Config ID** | `EagleEndurance` |
| **Config section** | `[Attribute Eagle Endurance]` |

</div>

<!-- IMAGE: Eagle Endurance attribute icon -->

## Effects

| Effect | Value |
| --- | --- |
| Base stamina | +25 |
| Stamina regeneration rate | 125% |
| Delay before stamina starts to regenerate | 0.5 s (vanilla: 1 s) |
| Stamina used when attacking | −20% |

- The extra stamina applies whatever food you have eaten.
