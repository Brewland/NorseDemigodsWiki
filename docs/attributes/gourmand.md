# Gourmand

Gourmand is Brokkr's own attribute: he regenerates health from food twice as fast when out of combat, and never feels
cold.

| | |

| **Condition** | Health bonus only out of combat |
| **Config ID** | `Gourmand` |

</div>

## Effects

| Effect | Value |
| --- | --- |
| Health regeneration from food, out of combat | ×2 (200%) |
| Cold status effect | Never applied |

- Out of combat means no enemy has noticed you, and you are not burning, poisoned, frozen, shocked or freezing.

## Notes

- Only the Cold effect is prevented. Freezing (for example in the Mountains without frost resistance) is a separate
  effect and still applies.
