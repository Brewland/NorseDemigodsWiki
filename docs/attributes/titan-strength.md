# Titan Strength

Titan Strength is Brokkr's own attribute: he moves freely in heavy equipment, carries much more, chops and mines faster
and uses less stamina when attacking.

| **Condition** | Always active |

</div>

## Effects

| Effect | Value |
| --- | --- |
| Movement penalty from equipment ignored | Up to 30% |
| Extra damage to trees with an axe | +75% |
| Extra damage to ores with a pickaxe | +50% |
| Stamina used when attacking | −30% |

## Scaling

Extra carry weight: 3 [per level](../reference/glossary.md#per-level).

| | Lv 0 | Lv 50 | Lv 100 |
| --- | ---: | ---: | ---: |
| Extra carry weight | 0 | 150 | 300 |

## Notes

- The movement penalty counts all equipment together.
- Example: 35% total penalty from [heavy armor](../reference/glossary.md#heavy-armor), weapon and shield slows
  you by only 5%.
