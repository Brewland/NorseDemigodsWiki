# Blacksmith

Blacksmith is Brokkr's own attribute: as the master forger among the demigods, his two-handed weapons block much more
damage and every crafting station he uses counts as one level higher.

<div class="nd-infobox" markdown>

| | |
| --- | --- |
| **Demigod** | [Brokkr](../demigods/brokkr.md) |
| **Condition** | Always active |
| **Config ID** | `Blacksmith` |
| **Config section** | `[Attribute Blacksmith]` |

</div>

<!-- IMAGE: Blacksmith attribute icon -->

## Effects

| Effect | Value |
| --- | --- |
| Block armor with two-handed weapons | +50% |
| Crafting station level | +1 |

## Notes

- The extra station level counts for recipe and upgrade requirements. Example: a level 6 Forge counts as level 7.
- The Cauldron does not get the bonus. Servers can change the excluded stations:
  `[Attribute Blacksmith] Ignored Crafting Stations List`.
