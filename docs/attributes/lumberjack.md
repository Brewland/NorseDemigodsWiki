# Lumberjack

Lumberjack is Ullr's own attribute: he swings axes faster and fells trees much faster.

<div class="nd-infobox" markdown>

| | |
| --- | --- |
| **Demigod** | [Ullr](../demigods/ullr.md) |
| **Condition** | Always active |
| **Config ID** | `Lumberjack` |
| **Config section** | `[Attribute Lumberjack]` |

</div>

<!-- IMAGE: Lumberjack attribute icon -->

## Effects

| Effect | Value |
| --- | --- |
| Attack speed with axes | +20% |
| Extra damage to trees with an axe | +75% |

- The attack speed bonus applies to every axe swing, in combat too.
