## Building locally

The site is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and deployed to GitHub Pages
on every push to `main`.

```sh
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/mkdocs serve
```
